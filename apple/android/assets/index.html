核心功能

    

      
⬇️
极速下载
镜像加速 + 多线程 + SHA1 校验，断网重试也不会重复下载。

      
🧩
四种加载器
Vanilla / Fabric / Forge / NeoForge 自动安装，版本号自动匹配。

      
🛠️
诊断与补全
逐项检查 jar、库、资源索引，精确指出缺了哪个文件，一键补回。

      
🧑‍🎨
3D 皮肤预览
OpenGL 实时渲染，支持帽子与外套第二层，可拖拽旋转。

      
🌐
一键联机
基于 EasyTier 的虚拟局域网，填房间号即可加入。

      
🎨
个性化
浅色 / 深色 / 跟随系统，毛玻璃开关，侧栏宽度可调。
